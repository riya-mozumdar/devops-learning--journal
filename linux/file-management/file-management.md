# Linux File Management Commands

## pwd
Print current working directory

Example:
pwd

## ls
List files and directories

Example:
ls
ls -l
ls -a

## cd
Change directory

Example:
cd /home/riya
cd ..

## mkdir
Create a new directory

Example:
mkdir test

## rmdir
Remove an empty directory

Example:
rmdir test

## rm -r
remove directory with all its content

Example:
rm -r demo

## touch
Create an empty file

Example:
touch file1.txt

## cp
Copy files and directories

Example:
cp file1.txt file2.txt
cp -r dir1 dir2

## mv
Move or rename files

Example:
mv file1.txt file2.txt
mv file1.txt /tmp

## rm
Remove files

Example:
rm file1.txt
rm -r directory

## cat
Display file contents

Example:
cat file1.txt

## less
View file contents page by page

Example:
less file1.txt

## head
Display first 10 lines

Example:
head file1.txt

## tail
Display last 10 lines

Example:
tail file1.txt

## find
Search for files and directories

Example:
find . -name "*.txt"

## chmod 
change file and directory permissions

Example : 
chmod 764 hello.txt

## chown
change the ownership of a file or directory

Example : 
chown riya hello.txt

## chgrp
change the group ownership of a file or repository

Example: 
sudo chgrp devops hello.txt
